# Changelog

## Description

This file records user-visible changes to wakindex. It follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Added a documented Semantic Versioning and tag-driven GitHub release process.
- Added automated release validation, Python package artifacts, and SHA-256 checksums.

### Changed

- Expanded installation, policy, manifest, GitHub Action, Docker, security, and development documentation.
- Reworked the architecture guide around trust boundaries, component contracts, compatibility, and safe extension.

## [0.1.0] - Unreleased

### Added

- Added the initial local-first scanner, policy engine, CLI, SARIF output, permission editor, Docker image, and GitHub Action.
- Added the two-part WAK / INDEX terminal banner and a restrained browser product heading.
- Added a concise description, quick-start commands, and an output divider to the CLI startup panel.

### Changed

- Limited the startup panel to `wakindex init` so scan, check, UI, and help output stay compact.
