# Security Policy

## Description

This document explains safe operation and how to report vulnerabilities in AgentScope.

AgentScope scans untrusted text but does not run configured agents, tools, or MCP commands. Secret detection stores names only. The UI listens on `127.0.0.1` and writes only the explicitly selected policy path.

Please report security issues privately through GitHub Security Advisories after publication. Do not include live credentials in reports or test fixtures.
